# readability-pass subagent 프롬프트 (한국)

원본 보고서 저장 후 입문자용 `-쉬운버전.md`를 생성하는 subagent.

## 호출 방법

SKILL.md Step 8에서 원본 저장 완료 후 `Agent` tool로 호출 (`subagent_type: general-purpose`). 순차 후처리 — 메인 워크플로우의 마지막 단계. `{원본 절대경로}`, `{glossary 절대경로}` 플레이스홀더만 치환.

## 프롬프트 본문 (subagent에 전달)

```
다음 한국 증시 보고서 원본을 입문자용으로 리라이팅해 같은 디렉토리에 `-쉬운버전.md` suffix로 저장하세요.

## 입력
- 원본 파일: {원본 절대경로} (예: /Users/musinsa/workspace/kr-market-report/2026-05-07.md)
- 한국 시장 용어집: {glossary 절대경로} (references/glossary-kr.md)

## 출력 규칙

### 1. 최상단: 📘 미니 용어집

용어집 파일을 Read 후 본문에 등장하는 용어 8-12개만 골라 다음 형식으로 본문 최상단에 삽입:

\`\`\`markdown
## 📘 미니 용어집
- **수급(需給)**: 외국인·기관·개인이 종목/시장을 사고 파는 거래 흐름. "외국인 매도세"는 외국인이 더 많이 팔았다는 뜻
- **외국인 보유 비중**: 종목별 외국인이 보유한 주식 수 / 전체 주식 수
- **공매도 잔고 비율**: 공매도된 주식 수 / 전체 상장 주식 수. 5% 초과 시 의무 공시
- ...
\`\`\`

원본에 등장하지 않은 용어는 용어집에 넣지 않음 (불필요한 정보 추가 금지).

### 2. 본문

원본의 섹션 구조와 순서 그대로 유지. 단:

**전문용어 첫 등장 시 괄호 해설 자동 삽입**
- ❌ "외국인 환손실 회피 가능성"
- ✅ "외국인 환손실 회피(원화 약세 시 외국인이 보유한 한국 주식의 달러 환산 가치가 떨어지므로 미리 매도하는 행동) 가능성"

**표 아래 "쉬운 해석" 한두 줄 추가**
\`\`\`markdown
| 시장 | 외국인 | 기관 | 개인 |
|---|---|---|---|
| KOSPI | -3,142억 | +2,876억 | +266억 |

> **쉬운 해석**: 외국인은 3,142억원 어치 더 팔고 기관은 2,876억원 어치 더 샀다는 뜻. 기관이 외국인의 매도를 어느 정도 받아냈지만 지수 하락은 막지 못한 모양이에요.
\`\`\`

**숫자/티커/URL은 원본 그대로 보존**
- 정확성 유지를 위해 숫자 단위·티커 코드·URL은 절대 변경하지 않음
- 단위가 어려우면 옆에 풀어쓰기 ("1,234억원 (= 1.2조원의 약 10%)")

**재해석 금지**
- 원본의 인과 분석을 풀어 쓰는 데 그치고 새로운 인과를 추가하지 말 것
- 원본에 없는 추측·전망·예측 추가 금지
- "~로 보입니다" 같은 hedge는 원본에 있을 때만 유지

### 3. 길이

원본 대비 +10~30%. 너무 길면 readability 떨어짐.

### 4. 파일 저장

같은 디렉토리에 `{원본_basename}-쉬운버전.md`로 Write.
- 원본: `2026-05-07.md` → 쉬운버전: `2026-05-07-쉬운버전.md`
- 원본: `2026-05-07-1820.md` (시간 suffix 있는 경우) → 쉬운버전: `2026-05-07-1820-쉬운버전.md`

### 5. YAML frontmatter

원본 frontmatter를 그대로 복사 + 추가 키:
\`\`\`yaml
readability_pass: true
source_report: {원본 파일명}
\`\`\`

## 절대 금지

- 원본에 없는 종목/지수/숫자 추가
- 원본의 인과 분석 결론 변경
- 출처 [[n]](url) 링크 제거 또는 변경
- "쉬운 해석"에 새로운 정보 추가 (원본 표를 풀어쓰기만)
- 보고서 채팅창 출력 (저장만)

## Fault tolerance

- 원본 파일 Read 실패 → 즉시 BLOCKED 보고
- 용어집 Read 실패 → 미니 용어집 섹션 생략하고 본문 처리만 진행
- Write 실패 → 메인에 "쉬운버전 생성 실패" 보고 (원본은 이미 디스크에 있음)
```

## 메인 세션의 응답 처리

readability-pass 완료 보고 수령 후:
- 성공 시 사용자에게 두 파일 경로 + TL;DR 보고
- 실패 시 "쉬운버전 생성 실패" 한 줄만 추가, 원본 경로는 정상 보고

# 라벨 자동 결정 규칙

보고서의 §3 수급 동향 / §4 업종 동향 최상단에 표기되는 두 라벨(`flow_label`, `sector_label`)을 자동 결정하는 규칙. YAML frontmatter에도 동시 기록.

## 1. 수급 라벨 (`flow_label`)

미국식 risk-on/off는 한국 시장에 안 어울림. 외국인이 한국 시장 흐름의 가장 큰 변수라 **수급 패턴 자체를 라벨**로 삼음.

### 결정 규칙 (단위: 억원)

| 라벨 | 조건 | 직관 |
|---|---|---|
| **외국인 컴백** | 외국인 KOSPI > +1,000 + KOSPI dp > 0 | 외인 매수세 진입, 지수 상승 |
| **외국인 이탈** | 외국인 KOSPI < -3,000 + KOSPI dp < 0 | 강한 외인 매도, 지수 하락 |
| **기관 단독 방어** | 기관 > +2,000 + 외국인 < -1,000 | 외인 매도를 기관이 흡수 |
| **수급 합세 강세** | 외국인·기관 모두 > +1,000 + KOSPI dp > 0.5% | 양매수 + 강세 |
| **삼중 매도** | 외국인·기관·개인 모두 < -500 | 매우 약세 |
| **개인 단독 매수** | 개인 > +3,000 + 외국인·기관 모두 < 0 | 개미 단독 받아냄 |
| **테마 순환** | KOSPI \|dp\| < 0.3% + 일부 업종 \|dp\| > 2% | 지수 보합 + 일부 섹터만 강세 |
| **혼조** | 위 어느 것도 매칭 안 됨 | default fallback |

### 결정 알고리즘

조건 매칭 시 **첫 번째 매칭 라벨 채택** (위에서 아래 순서). 매칭 라벨 없으면 "혼조".

### 입력 데이터

- 외국인 KOSPI / KOSDAQ 순매수: pykrx `kr_flow_market.py` 결과
- 기관 / 개인 순매수: 동일
- KOSPI dp / KOSDAQ dp: pykrx `kr_indices.py` 결과
- 업종별 dp: pykrx `kr_sector.py` 결과 (테마 순환 판정용)

## 2. 섹터 로테이션 라벨 (`sector_label`)

KRX 21개 업종을 5그룹으로 묶어 평균 변동률 기반 라벨링.

### KRX 21개 업종 → 5그룹

```
시클리컬: 전기전자, 화학, 철강금속, 운수장비, 건설업
방어:    통신업, 전기가스, 의약품, 음식료품
금융:    금융업, 보험, 증권, 은행
성장:    의료정밀, 비금속광물, (코스닥 IT/바이오)
인프라:  운수창고, 유통업, 서비스업
```

각 그룹의 평균 dp 계산 후 라벨 결정.

### 라벨 규칙

| 라벨 | 조건 |
|---|---|
| **시클리컬 강세** | 시클리컬 평균 dp > +1% AND 방어 평균 dp < 0 |
| **방어주 강세** | 방어 평균 dp > +0.5% AND 시클리컬 평균 dp < -0.5% |
| **수출주 강세** | 시클리컬 강세 조건 + USD/KRW dp < 0 (원화 강세) |
| **내수주 강세** | (인프라 OR 금융) 평균 dp > 시클리컬 평균 + USD/KRW dp > 0 (원화 약세) |
| **코스닥 우세** | KOSDAQ dp > KOSPI dp + KOSDAQ dp > +0.5% |
| **혼조** | 위 어느 것도 매칭 안 됨 |

### 결정 알고리즘

- "수출주 강세"와 "시클리컬 강세"는 동시 매칭 가능 — **수출주 강세 우선** (더 specific)
- "내수주 강세"와 "방어주 강세" 동시 매칭 가능 — **내수주 강세 우선**
- 그 외 첫 번째 매칭 라벨 채택

## 3. 적용 위치

- `flow_label`: 본문 §3 수급 동향 최상단 (`**라벨**: 외국인 이탈`)
